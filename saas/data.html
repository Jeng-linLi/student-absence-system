3. Schema Excerpts結構節錄

Core tables shown; full DDL in schema.sql. 此處僅列核心表，完整定義見 schema.sql。

CREATE TYPE absence_category AS ENUM (
  'medical','university_activity','sports_competition','conference',
  'family_emergency','visa_immigration','bereavement','personal','other'
);

CREATE TYPE request_status AS ENUM (
  'draft','pending','info_requested','approved','rejected','withdrawn','expired'
);

CREATE TABLE absence_requests (
    id               UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    reference_no     VARCHAR(20) NOT NULL UNIQUE,   -- SAAS-2026-001234
    student_id       UUID NOT NULL REFERENCES users(id),
    category         absence_category NOT NULL,
    start_date       DATE NOT NULL,
    end_date         DATE NOT NULL,
    start_period     CHAR(2) NOT NULL DEFAULT 'AM', -- AM | PM
    end_period       CHAR(2) NOT NULL DEFAULT 'PM',
    days             NUMERIC(4,1) NOT NULL,         -- 半天計 0.5
    reason           TEXT NOT NULL,
    status           request_status NOT NULL DEFAULT 'pending',
    route_code       VARCHAR(20) NOT NULL,          -- A-MED | B-OFFICIAL | C-LONG
    route_version    INTEGER NOT NULL DEFAULT 1,
    current_level    INTEGER NOT NULL DEFAULT 1,
    required_levels  INTEGER NOT NULL DEFAULT 1,
    auto_verified    BOOLEAN NOT NULL DEFAULT FALSE,
    sla_due_at       TIMESTAMPTZ,
    submitted_at     TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT chk_date_range   CHECK (end_date >= start_date),
    CONSTRAINT chk_days_positive CHECK (days > 0)
);

CREATE TABLE accommodations (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    conflict_id       UUID NOT NULL REFERENCES assessment_conflicts(id) ON DELETE CASCADE,
    type              accommodation_type NOT NULL,  -- excused|make_up|alternative_assignment
                                                    -- |weight_redistribution|rejected
    decided_by        UUID NOT NULL REFERENCES users(id),
    new_deadline      DATE,
    make_up_date      DATE,
    make_up_venue     VARCHAR(80),
    weight_before_pct NUMERIC(5,2),
    weight_after_pct  NUMERIC(5,2),
    rejection_reason  TEXT,
    decided_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT chk_reject_reason CHECK (type <> 'rejected' OR rejection_reason IS NOT NULL)
);

Every index is justified by a measured query pattern; no speculative indexes. Quarterly review removes unused indexes (via pg_stat_user_indexes). 每個索引都對應經量測的查詢模式，不做投機性建索引；每季依 pg_stat_user_indexes 清除未使用索引。

7. Document Verification & Fraud Prevention文件核實與防欺詐

  • Integrity: SHA-256 per document; identical hashes across different students are flagged for review. 完整性：每份文件計算 SHA-256；不同學生出現相同雜湊即標記複查。
  • Malware: every upload is virus-scanned before it becomes readable; infected files are quarantined. 防毒：每次上傳先掃描方可讀取；感染檔案隔離。
  • Provenance: Blob paths are private-endpoint only; documents are served through short-lived signed URLs (5 min) and every access is logged. 來源：Blob 僅經私有端點存取；文件透過 5 分鐘有效期的簽章網址提供，每次存取均記日誌。
  • Retroactive roster abuse: event_participants.added_at is immutable; a student added after the absence dates cannot be auto-verified. 事後補名單：event_participants.added_at 不可修改；請假日期後才加入名單者不得自動核實。
  • Pattern detection: repeated medical certificates clustering immediately before assessments raise EW-3 for confidential review (never shown to instructors). 模式偵測：集中出現在考評前的重複病假證明會觸發 EW-3 保密複查（不會顯示給教師）。
  • SLA gaming: escalation is automatic and recorded; delegation chains are capped at 2 hops to prevent indefinite passing. 拖延審批：升級自動化並留痕；代理鏈最多兩跳，避免無限期轉派。
