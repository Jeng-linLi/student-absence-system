2. Proposed Solution方案概述

SAAS is a single web + mobile platform covering three previously disconnected processes — absence requests, assessment conflict resolution, and official activity verification — behind one workflow engine, one notification bus, and one analytics layer. SAAS 以一套網頁 + 流動應用，統一承載三條原本割裂的業務線：請假申請、考評衝突處理、官方活動核實；共用同一工作流引擎、同一通知總線與同一分析層。

One submission一次提交

Student fills one form; SAAS resolves affected courses and assessments automatically and routes to the right approvers. 學生只填一次表；系統自動解析受影響課程與考評，並分派給正確審批人。

One workflow engine統一工作流引擎

Configurable, rule-driven approval chains (medical / official activity / long absence) with SLA timers and escalation. 規則驅動、可配置的審批鏈（病假／官方活動／長期請假），附 SLA 計時與升級機制。

One source of truth單一事實來源

Every action is logged; every document is versioned; every report is reproducible from the same ledger. 所有操作留痕、文件版本化、報表可從同一帳本重現。

4. MVP Scope (Phase 1 · 12 weeks)MVP 範圍（第一期 · 12 週）

  • SSO via Azure AD / Microsoft Entra ID; RBAC for all 9 roles 以 Azure AD（Entra ID）單一登入；9 種角色 RBAC 權限
  • Absence request submission with 9 categories + document upload (Azure Blob) 9 類請假申請＋證明文件上傳（Azure Blob）
  • Workflow engine: Case A (medical) / Case B (official activity auto-verify) / Case C (>7 days) 工作流引擎：A 病假／B 官方活動自動核實／C 七天以上
  • Instructor decision queue with 5 accommodation options + conflict detection 教師決策佇列，含 5 種學業便利方案與衝突偵測
  • Official activity module: create event, upload roster, auto-verification 官方活動模組：建活動、上傳名單、自動核實
  • Notifications: email (Exchange Online) + Teams adaptive card + in-app 通知：電郵（Exchange Online）＋ Teams 卡片＋站內
  • Student / Instructor / Program Office dashboards + 5 core reports 學生／教師／項目辦公室看板＋5 份核心報表
  • Audit logging, encryption at rest & in transit, WCAG 2.1 AA 操作日誌、靜態與傳輸加密、WCAG 2.1 AA 無障礙

Deferred to Phase 2 / 3（第二、三期）: native mobile app, WeChat mini-program & SMS channel, early-warning risk scoring, advanced analytics, LMS-grade attendance sync. 原生流動應用、微信小程序與短信通道、風險預警評分、進階分析、與 LMS 出席資料深度同步。
