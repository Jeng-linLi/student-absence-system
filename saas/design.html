Accessibility & Responsive Rules無障礙與響應式規則

WCAG 2.1 AA無障礙

  • Contrast ≥ 4.5:1 for all text; ≥ 3:1 for UI components文字對比 ≥4.5:1，元件 ≥3:1
  • Full keyboard navigation with visible focus rings完整鍵盤操作與可見焦點框
  • Status conveyed by colour + icon + text狀態以色＋圖示＋文字並行表達
  • Every form field has a persistent visible label所有欄位具持續可見標籤
  • Error messages identify the field and how to fix it錯誤訊息指明欄位與修正方式
  • Screen-reader announcements for async status changes非同步狀態變更會向螢幕閱讀器播報
  • Target size ≥ 44×44 px on touch觸控目標 ≥44×44 px
  • No content flashes more than 3 times per second內容每秒閃爍不超過三次

Breakpoints斷點

≥ 1280 pxFull 3-column workspace; persistent side nav三欄工作區，側欄常駐
1024–1279 px2-column; navigation collapses to icons雙欄，導覽收合為圖示
768–1023 pxSingle column; nav becomes a drawer單欄，導覽改為抽屜式
< 768 pxMobile layout = native app parity; bottom tab bar手機版面，與原生應用一致，底部頁籤

Bilingual layout: Chinese strings are typically 40–60% shorter than English, so buttons use min-width with wrapping rather than fixed width; date and number formats follow locale. 雙語版面：中文通常較英文短 40–60%，故按鈕採最小寬度＋換行，而非固定寬度；日期與數字格式依語系顯示。
