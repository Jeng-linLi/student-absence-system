# 線上請假系統（原型 v0.1）

學生線上提交假單 → 導師審批 → （必要時）院系複核 → 核准生效。Flask + SQLite，開箱即跑。

## 啟動

```bash
# 或雙擊 start.bat
"C:\Users\Johnny\.workbuddy-ai\binaries\python\envs\default\Scripts\python.exe" app.py
```

打開 <http://127.0.0.1:5055>。首次啟動自動建庫並寫入示範資料。

## 審批規則

- 請假 **≤ 3 天**：導師核准即生效。
- 請假 **> 3 天**，或假別標記「需院系審批」（公假、喪假）：導師核准後自動轉院系複核。
- 病假**必須**上傳證明文件。
- 駁回必須填寫理由，理由會通知學生。
- 天數按半天粒度計：同日 AM→PM = 1 天，同日 AM→AM = 0.5 天。

## 功能清單

| 角色 | 功能 |
|---|---|
| 學生 | 提交假單（含附件）、我的假單（按狀態篩選）、撤回、查看審批進度與操作日誌 |
| 導師 | 待我審批、全部假單、核准/駁回、班級請假統計、CSV 匯出 |
| 院系 | 同上（第 2 級複核，範圍為所屬院系） |
| 管理員 | 帳號增刪/停用、假別管理（是否需證明、是否需院系） |

共通：站內通知、操作日誌（誰在何時做了什麼）、淺色/深色主題切換。

## 上生產前還要補

1. **認證**：接學校 SSO / CAS，替換本地帳號；密碼改由 IAM 託管。
2. **安全**：CSRF token、`SECRET_KEY` 走環境變數、上傳檔案做病毒掃描與白名單校驗、SQL 已參數化但需加審計留存。
3. **部署**：換 Gunicorn/Waitress + Nginx，SQLite 換 PostgreSQL。
4. **業務**：假期額度上限、學期/校曆（排除假日扣天數）、銷假流程、與教務考勤系統對接、郵件/企業微信通知。
5. **合規**：個資（請假事由、病假證明）保存期限與存取權限需符合學校與《個人信息保護法》要求。
